# 卷纲与章纲来源及映射

灵感 -> 卷纲（固定节点模型） -> 每节点一章 -> 章内目标、冲突、行动、结果。

一节点一章为用户指定的产品规则，非文学理论。三幕3、七点7、故事环8、救猫咪15、四幕4、五幕5、八序列8、Vogler英雄之旅12、起承转合4、序破急3、特鲁比7、麦基5、因果链6。后三类工程/组织方法不强行按数字定章数。

核对资料：
- https://gwuwi.com/wp-content/uploads/2016/04/dan-wells-storystructure-condensed.pdf — Dan Wells内容授权署名的七点讲义。
- https://savethecat.com/wp-content/uploads/2013/12/STC_BeatSheetRev3.pdf — 官方十五节拍。
- https://channel101.fandom.com/wiki/Story_Structure_101:_Super_Basic_Shit — Dan Harmon原文存档。
- https://www.studiobinder.com/blog/three-act-structure/ — 三幕说明。
- https://truby.com/video/ — 作者关于前提与七步的视频。
- https://www.advancedfictionwriting.com/articles/snowflake-method/ — 作者的雪花法十个设计步骤，不是十章。

其余简化模型按本轮用户提供的节点文本配置，不声明统一官方版本。旧卷纲缺结构默认七点，新生成卷纲明确保存结构。VM测试全部固定结构数量、来源和节点对应；浏览器核对七点生成及采用完整7章、三幕动态3章及书内来源。
