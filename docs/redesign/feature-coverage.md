## 一致性约定

- 新模块沿用现有语义色、模块窗口、列表详情布局、原生 select、分页和通知。顶部仍只有首页，左侧新增两个唯一模块入口，小窗口“更多页面”包含它们。
- 卡片表单由 `preview-features.js` 的 `openEditor` 统一拥有；阅读添加复用同一导入页，文本拆分和导出序列化各只有一个纯逻辑入口。全局搜索继续由 `preview-search.js` 唯一拥有，不增加页面局部搜索。原生 select 的弹出层由操作系统拥有，不另建自绘菜单。
- 新移除操作消费入口定义的 `--danger` / `--danger-soft`，其他文字、品牌色、边界和窗口继续复用原语义变量。
- 新卡片共享一个表单弹窗，必填标题、可选描述和标签；场景另有氛围字段。保存、取消、Esc、字段校验和关闭后焦点恢复一致。
- 卡片移除只影响本页，弹窗明确对象，并提供撤销；刷新恢复示例。不用原生 alert/confirm/prompt。
- 阅读样例为自写文本。笔记按阅读书、分类独立保留；切章及离开再返回不丢本页输入。AI 自动拆解不伪装为已执行。
- 导入只追加，不覆盖现有章节；先展示拆分结果，再提交。预览支持 UTF-8 TXT/MD，单文件最多 2 MiB；验证类型、大小、编码和空内容，保留错误时的原输入。异步文件读取使用代号忽略过期结果。
- 导出只包括用户选中的本页演示章节，明确文件名和预览用途；使用共享纯文本序列化逻辑。真实 JSON 工作区恢复、DOCX 富文本转换和 AI 服务留给正式版本接入，不创建误导按钮。
- 导出使用原生下载链接；本次内置浏览器检查未取得下载文件路径，磁盘保存尚未证实。导出内容、选章与格式已经验证，保存结果需在支持下载的浏览器或正式 Electron 环境复核。
- 卡片、阅读正文和全部拆书笔记接入既有唯一全局搜索；跨分类/章节定位须准确，隐藏内容也可检索。密钥与服务配置仍不入索引。
- 新可滚动列表各自拥有滚动，父页面不固定高度；窄窗口堆叠阅读与笔记，输入框自增长，支持减少透明效果。

## 验证范围

第十六版：书内人物库与全局人物资料库采用不同入口、标题、面包屑和导航高亮。人物资料库复用现有资料分类及归档数据，来源入口回到书内修改。作品首页可直接进入当前作品的人物库及世界观库；世界观仍使用类别、名称、介绍三字段，资料库世界观库接收同步记录。资料分类写入 URL，刷新恢复对应页；窄屏更多页面保留人物资料库入口。

第十五版：人物卡精简为姓名、身份、所属、介绍、目标与动机；世界观卡精简为类别、名称、介绍。人物和世界模板同步同一份核心资料，保留来源作品和同步状态。目标与动机加入全局搜索及定位，保留既有书内删除后归档留存规则。人物生成可选择当前作品的灵感，生成、修改、采用目标段落；刷新恢复示例。

纯逻辑验证章节切分、序列化和搜索；实际浏览器验证新增、编辑、校验、取消、分页、移除撤销、阅读与笔记保持、导入追加、全局定位、导出及窄窗口。结果记录于设计评审文档。


第23版：练习由 preview-practice.js 接管，支持题材与任务、三个演示主题、约300字正文、浏览器持久化、版本历史、真实统计、人工核对、题材筛选和累计档案；保存的练习加入全局搜索。详情与验证见 2026-10-04-practice-review.md。


第24版补齐分析修改与累计文风审核、证据变化重审、审核草稿恢复；生成窗口资料选择和确定性终验共用一个所有者。文风范围与适用纠正可查看，仍属于独立交互预览。

## 第 25 版阅读流程补齐

参考书分类删除。整本 TXT / 单章粘贴共用导入表单（UTF-8、GBK，阅读稿 20 MiB / 2000 章）。阅读稿、笔记、分析记录及带来源的创作参考通过 IndexedDB 本机保留。片段 → 摘录与报告，采样整书 → 结构与报告，技巧 → 写作技巧。四维观察手动收录后按任务出现在共享 AI 输入参考选择中。不会自动并入个人文风；仍不调用真实 AI。
