# 写作台桌面测试版

当前入口是 **Electron**，沿用已确认的彩虹玻璃界面。功能已接入本机 SQLite 和 OpenAI 兼容的 AI 服务。Windows x64 安装包版本为 **0.2.0**，安装与数据保留说明见 [发布说明](RELEASE.md)。源码仓库为 [soryuu914-svg/soryuu](https://github.com/soryuu914-svg/soryuu)。

双击根目录的 **启动写作台.cmd** 即可打开保护构建。无需启动 127.0.0.1 的网页服务器。测试方法见 [桌面测试说明](TESTING.md)。

## 数据与使用

- 开发测试数据：项目 `.desktop-data/writing-workbench.sqlite3`。安装版首次启动在软件可执行文件同级生成数据库，重新打开继续读取。独立安装验收已覆盖首次建库、重开、覆盖安装和卸载保留数据库与备份。
- 作品、正文、人物、世界观、大纲、伏笔、灵感、金手指、阅读稿、练笔、人工核对、资料和生成记录统一保存在 SQLite。设置里显示实际数据库路径。
- 人物与世界资料保留独立初始版本和书内最新版本；删除书内卡片保留公共资料归档。
- 新书默认没有示例正文。公共技巧和避雷资料可以内置，AI 需要在设置中填写服务地址、模型和自己的密钥。
- 默认由一个 AI 负责生成，再用独立调用核对；正文有问题时最多局部修订一次并再次核对。可选审核模型。
- 生成候选确认后才采用，撤销会协调恢复正文和伏笔状态。函数检查和审核降低出错风险，不能保证长篇小说永不跑偏。
- 保存失败会明确显示；可用“另存当前内容”导出尚未写入数据库的内容。完整 JSON 导出不含密钥；导入和数据库恢复前先备份。

## 工程入口

`desktop/` 是新桌面运行层；`docs/redesign/` 是当前界面的模块源码，仍可用于独立设计预览。`src/`、`src-tauri/` 保留旧版业务和迁移参考，旧依赖尚在工程中，新桌面启动不加载它们。

```text
npm run dev       开发构建并启动 Electron
npm run build     生成保护构建，不制作安装包
npm start         启动已有保护构建
npm test          桌面单元与集成函数测试
npm run verify    校验保护构建、脚本和桌面测试
npm run package:win  校验保护构建并生成 Windows x64 安装包
```

旧 React/Tauri 参考工程的命令分别为 `legacy:dev`、`legacy:build`、`legacy:test`、`legacy:tauri`。它们不代表本次桌面产品入口。

## 验证与保护范围

自动测试覆盖本机 HTTP 服务调用、取消、格式/引用校验、审核与修订、SQLite 重开、备份恢复、迁移、多书隔离、初始/最新模板、章节关联和应急导出。另有实际 Electron 窗口测试。测试使用本机可控的模型响应验证连接和操作流程，**未替用户验证真实公网模型的文学质量**。

保护构建包括脚本混淆、无 source map、AI 引擎 AES-GCM 加密后在内存加载、ASAR 资源封装、资源完整性检查、渲染进程沙箱和受限业务接口。客户端仍包含解密所需信息，完整性清单也未用发布签名锚定；这些措施增加分析成本，不能保证不可破解。当前安装包未使用商业代码签名证书；更新通过手动覆盖安装完成，没有自动更新器。

更详细的路径和边界见 [桌面平台约定](DESKTOP-PLATFORM.md)，本轮实现与验证记录见 [实施计划](docs/superpowers/plans/2026-10-04-desktop-release.md)。
